QATS Trader API

REST trading API for QATS Prop, a prop trading program for crypto and TradFi perpetuals. Connect your own bot, script or TradingView strategy to a prop account: market data, account risk, orders, executions, positions and command recovery.

What you can build

  • Trading bots in Python, JavaScript or any language that speaks HTTPS.
  • TradingView webhook alerts and Pine strategies sent to the same order routes.
  • Your own tools around a prop account: journals, risk dashboards, position sizing and reconciliation.
